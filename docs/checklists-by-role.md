# Приложение А. Чек-листы по ролям в согласовании договоров

К ТЗ `docs/tz-checklists-contract-approval.md`. Версия 0.1 (черновик).

> Перечень ролей собран по типовой практике договорной работы, так как исходный документ
> на Google Drive закрыт для доступа (требуется авторизация). После получения документа роли
> сверяются один-в-один, пункты перераспределяются между ролями без изменения формата.

## Как читать чек-листы

Каждый пункт сформулирован как **проверяемое утверждение**: согласующий отвечает
«Да / Нет / Не применимо». Ответ «Нет» означает несоответствие и создаёт замечание.

| Обозначение | Значение |
|---|---|
| **Б** | Блокирующий: шаг нельзя согласовать, пока замечание не закрыто |
| **З** | Значимый (major): замечание обязательно к отработке, но маршрут продолжается |
| **И** | Информационный: фиксация факта для истории и аналитики |
| ⚙ | Автопроверка: значение подставляет система, человек подтверждает или переопределяет |
| ⊕ | Требуется вложение (документ-подтверждение) |
| ⟳ | Пункт сбрасывается в «требует перепроверки» при новой версии договора |

Условная применимость указана в скобках курсивом — пункт показывается только при выполнении
условия (см. раздел 5.3 ТЗ).

и значимым: информационные переводятся в автоматический сбор без участия человека.

## 13. Правила распределения пунктов между ролями

Чтобы не возникало дублирования и споров о зоне ответственности:

1. Один пункт — одна ответственная роль. Если два согласующих смотрят один и тот же аспект,
   у одного из них пункт информационный либо удаляется.
2. Реквизиты контрагента: сверка с ЕГРЮЛ — юрист (правоспособность) и бухгалтер (реквизиты
   для платежей и первички). Это разные цели, дублирование допустимо осознанно.
3. Налоговый режим контрагента и НДС — только бухгалтер. Юрист проверяет лишь наличие
   налоговой оговорки как правового инструмента.
4. Бюджет и лимиты — только финансист. Руководитель инициатора подтверждает потребность,
   а не наличие лимита.
5. Проверка надёжности контрагента — безопасность. Финансист смотрит платёжеспособность
   применительно к авансу, а не общую благонадёжность.
6. Условия ответственности и неустойки формулирует юрист; финансист оценивает их
   достаточность в деньгах.
