# Приложение А к ТЗ. Чек-листы согласования договора по ролям

К ТЗ `docs/tz-checklists-contract-approval.md`. Версия 0.2.
Основание: Правила управления договорами, доверенностями и внешней корреспонденцией
ТОО «Көркем Телеком» (`KT_RULE_..._v1`), раздел 4 и Приложения 2, 3, 4, 7.

Документ раскрывает 30 укрупнённых блоков Приложения 3 Правил в конкретные пункты
подтверждения по каждой роли и добавляет пункты исполнения и закрытия по Приложению 4.
Роли и границы ответственности взяты из Приложения 2 Правил без изменений.

## Как читать

По каждому пункту согласующий выставляет один из четырёх статусов Правил (п. 3.1):
**Подтверждено**, **Не применимо** (с обязательным обоснованием), **Требуется доработка**
(автоматическая блокировка), **Остаточный риск** (блокировка до решения уполномоченного лица).
Статус «согласовано с замечаниями» не используется (п. 3.1.1).

| Обозначение | Значение |
|---|---|
| ⚙ | автопроверка: значение подставляет система, роль подтверждает или переопределяет с обоснованием |
| ⊕ | требуется вложение-доказательство |
| ⟳ | подтверждение аннулируется при существенном изменении документа (п. 3.2.2) |
| ! | остаточный риск недопустим: пункт устраняется только доработкой либо получением решения (п. 8.8) |
| *курсив* | условие применимости: пункт показывается только при выполнении условия |

Столбец «Блок» — ссылка на блок Приложения 3 Правил, который раскрывает пункт;
«П4» — пункт относится к Приложению 4 (исполнение и закрытие).

меньше. Ориентир для типового договора услуг с резидентом, плательщиком НДС, без аванса,
персональных данных, IP и филиала: ДПВ около 27 пунктов, Бухгалтерия около 16,
Финансы около 12, Инициатор около 20 (включая этап после подписания), остальные роли 6–9.

Если на пилоте у роли получается более 20 активных пунктов, приоритет отдаётся пунктам
с признаком «!» и пунктам с автопроверкой; остальные пересматриваются бизнес-владельцем
по накопленной статистике замечаний (п. 10.8 Правил).

## 14. Разграничение ответственности при пересечениях

Приложение 3 Правил прямо предусматривает совместную ответственность по ряду блоков.
Реализуется как разные пункты у разных ролей с разным предметом проверки:

| Блок | Роли | Разграничение |
|---|---|---|
| 3. Контрагент | Инициатор / организатор закупки, ДПВ, Бухгалтерия | Инициатор — достоверность введённых данных (`INI-06`); ДПВ — правоспособность и статус (`LAW-01`, `LAW-02`); Бухгалтерия — реквизиты для платежей и первичных документов (`ACC-01`) |
| 5. Наш подписант | Инициатор, ДПВ, Подписант | Инициатор — указание подписанта (`INI-12`); ДПВ — подтверждение полномочий (`LAW-04`); Подписант — соответствие сделки своим полномочиям (`SGN-03`) |
| 7, 9. Объём и сроки | Инициатор, техническое подразделение | Инициатор — соответствие потребности (`INI-08`, `INI-09`); техническое подразделение — техническая непротиворечивость и реалистичность (`TEC-03`, `TEC-04`) |
| 12. Цена и сумма | Инициатор, Финансы, Бухгалтерия | Инициатор — совпадение с договорённостями (`INI-10`); Финансы — согласованность цены и предел обязательств (`FIN-03`, `FIN-04`); Бухгалтерия — арифметика и НДС (`ACC-08`) |
| 14. Оплата | Финансы, Бухгалтерия | Финансы — исполнимость условий оплаты и денежный поток (`FIN-08`–`FIN-10`); Бухгалтерия — техническая возможность платежа и учёт аванса (`ACC-17`, `ACC-19`) |
| 15. Учёт и налоги | Бухгалтерия, ДПВ | Бухгалтерия — налоговый статус, ЭСФ, первичные документы (`ACC-05`–`ACC-15`); ДПВ — правовые оговорки налогового характера (`LAW-24`) |
| 20. Конфиденциальность | ДПВ, ИБ | ДПВ — формулировки, исключения, срок (`LAW-20`); ИБ — режим информации и требования к персоналу контрагента (`SEC-11`, `SEC-07`) |
| 21. Данные и доступ | ИБ, ДПВ, техническое подразделение | ИБ — состав данных, режим доступа, меры защиты (`SEC-01`–`SEC-10`); ДПВ — правовые условия обработки (`LAW-21`); техническое подразделение — техническая реализуемость мер (`TEC-10`) |
| 22. IP, ПО, лицензии | ДПВ, техническое подразделение | ДПВ — объём прав и гарантии (`LAW-22`); техническое подразделение — состав передаваемых артефактов (`TEC-09`) |
| 23. Compliance | Compliance, ДПВ, Финансы | Compliance — проверка контрагента и фактических обстоятельств (`CMP-01`–`CMP-09`); ДПВ — оговорки и правовая позиция (`LAW-23`); Финансы — платёжеспособность (`FIN-15`) |
| 25. Приложения | Инициатор и каждое профильное подразделение | Инициатор — комплектность и соответствие основному тексту (`INI-16`); ДПВ — правовые противоречия (`LAW-27`); техническое подразделение — технические приложения (`TEC-13`) |
| 26. Язык и перевод | Инициатор, ДПВ | Инициатор — наличие и согласованность версий (`INI-17`); ДПВ — приоритетная версия и соответствие перевода (`LAW-30`) |
| 27. Замечания | Каждый согласующий, ДПВ | Каждый — подтверждение устранения своего замечания; ДПВ — итоговый контроль отсутствия открытых замечаний (`LAW-33`) |
| 29. Остаточный риск | ДПВ, CEO | ДПВ — оформление карточки риска и рекомендация (`LAW-34`); CEO — решение (`CEO-01`–`CEO-06`) |
| 30. Допуск к подписи | ДПВ, Подписант | ДПВ — проверка маршрута, статусов, версии и полномочий (`LAW-35`); Подписант — итоговое решение (`SGN-01`–`SGN-07`) |
