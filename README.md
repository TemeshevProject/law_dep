# law_dep

Документация Департамента по правовым вопросам ТОО «Көркем Телеком».

## Чек-листы согласования договоров в SimBASE

Реализация чек-листов договорного процесса по Правилам управления договорами,
доверенностями и внешней корреспонденцией (`KT_RULE_..._v1`): раздел 4 и Приложения 2, 3, 4, 7, 8.

| Документ | Содержание |
|---|---|
| [Краткое ТЗ по ролям](docs/tz-checklists-short.md) ([Word](docs/tz-checklists-short.docx)) | Выжимка на 11 страниц: что проверяет каждая роль и её чек-лист. Для обсуждения с подразделениями |
| [ТЗ: чек-листы согласования договоров](docs/tz-checklists-contract-approval.md) | Требования к реализации в SimBASE: статусы и блокировки, аннулирование подтверждений при изменении версии, остаточный риск, допуск к подписанию, модель данных, API, приёмочные критерии, соответствие Приложению 8 А Правил |
| [Приложение А: чек-листы по ролям](docs/checklists-by-role.md) | 180 пунктов подтверждения для 12 ролей, матрица разграничения ответственности и соответствие 30 блокам Приложения 3 Правил |
| [Приложение Б: формат шаблонов](docs/checklists/contract-approval-checklists.yaml) | Машиночитаемые шаблоны чек-листов для настройки и импорта в SimBASE |
| [Единый документ Word](docs/tz-checklists-contract-approval.docx) | ТЗ вместе с Приложениями А и Б: титульный лист, оглавление, альбомная ориентация — для рассылки на согласование |

Документы Word собираются из исходных файлов (требуется pandoc 3.x):

```bash
python3 tools/build-docx.py --target full    # подробное ТЗ с приложениями
python3 tools/build-docx.py --target short   # краткое ТЗ по ролям
```

После правки текста пересоберите нужный файл и зафиксируйте его вместе с правками.

Статус: черновик версии 0.2. Требуют решения бизнес-владельца пороговые значения,
перечень пунктов, не допускающих остаточного риска, и незаполненные значения самих Правил
(см. раздел 14 ТЗ).
